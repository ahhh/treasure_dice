Class features, spells, species, backgrounds and rules are paraphrased and adapted to a rank-based, dice-tray game. `docs/rules-coverage.json` records, for every feature and spell, whether it is implemented exactly, adapted, or narrative only. The same tag appears on every hero sheet in the game.

## Original content

The Fortune Tray, charms, omens, curses, dice materials, monsters, biomes, events, items' affixes, story text and all artwork are original to Treasure Dice. The art was generated for this project with the house-style pipeline in `~/Programming/image_gen_pipeline/treasure_art`.

## External services

No external API (including the Lockboxx generators named in the design plan) is contacted at runtime. The game is fully playable offline once loaded.
